# 国海工业研究图库

本仓库是面向客户的浏览与临时试画版本，只包含公开网页运行所需的前端文件和经过精简的数据，不包含内部原始数据文件、数据库、备份或内部操作日志。

客户可以在“草稿指标工厂”构建本机草稿指标，并继续用于临时试画。草稿和试画只保存在其自己的浏览器，不会修改正式数据库、正式图表或线上仓库；清除该网站的浏览器数据会同时清除草稿。可以使用页面顶部的导出与导入按钮，把本机草稿包迁移到另一浏览器。
