# 国海工业研究图库

本仓库是面向客户的浏览、作图和导出版本，只包含公开网页运行所需的前端文件和完整公开数据，不包含原始 Excel、SQLite、备份或内部操作日志。

客户可以在“草稿指标工厂”构建本机草稿指标，并继续用于临时试画。草稿由IndexedDB保存在其自己的浏览器，不会修改发布者的正式数据库、正式图表或GitHub仓库；请定期使用“导出完整工作包”备份。
